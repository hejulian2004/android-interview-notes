# 认证编辑后端

本目录实现登录、服务端 GitHub 读取/写回和 Agent。站点状态见 [网站说明](../README.md)；生产密码、密钥和私密运维记录不保存在公开仓库中。

## 数据流与边界

浏览器的题库读取、强制刷新、编辑、源码查询和模型请求全部发往同源 `/android-study/api/`。公开构建只含 UI、Markdown 渲染与纯解析器，不含打包题库或旧版浏览器 GitHub 加载器。GitHub、模型密钥只在后端使用，不写入响应、草稿或浏览器 localStorage。

Python 3.10+ 标准库运行，无额外 Python 生产依赖。现有服务器 SSH 凭据模式另需 Git 与 OpenSSH；使用明确配置的现有身份和 known_hosts，不复制密钥、不创建新 PAT。后端只接受数字 loopback 监听地址，由既有 Caddy 提供 HTTPS；不开放新公网端口。当前为单管理员、单进程服务。会话、题库缓存、幂等结果、源码外发授权、模型设置、近期对话和每日限额均在进程内存中；重启使会话与待确认服务端草稿失效。浏览器本地草稿和学习进度保留，GitHub 已确认提交永久保留。多进程共享状态、持久缓存和跨设备进度同步不在本版范围。

## 登录与 API

`POST login` 校验显式配置的管理员密码哈希，签发短时 HS256 JWT access cookie 和可撤销、轮换的 refresh cookie。默认 access 15 分钟、会话绝对上限 7 天；Cookie 使用 HttpOnly、Secure、SameSite=Strict，仅限 API 路径。JWT 严格核验算法、签名、issuer、audience、expiry 和服务端会话代数。退出与续期会撤销旧令牌，重启撤销全部会话。

除登录外，所有业务 API 都验证管理员会话；所有 POST/PUT 还验证精确 Origin 和 `X-CSRF-Token`。GET session 用于恢复当前同源会话；访问令牌过期但 refresh 有效时，前端先获取 CSRF 再续期。请求头与正文有 15 秒总读取期限，完成后才解除并进入长业务处理。可信代理 peer 必须显式配置，只有其被覆盖的单值客户端 IP 头参与限流。登录失败限流、JSON 大小限制、请求并发限制和安全错误信息均由服务器执行，不依赖前端隐藏按钮。

主要接口（相对 `/android-study/api/`）：

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET/POST | session、login、session/refresh、logout | 会话读取、登录、续期、退出（按各接口适用方法） |
| GET / POST | catalog / catalog/refresh | 服务器题库缓存 / 强制检查 GitHub |
| GET | edit?questionId=... | 返回可编辑原文、原提交 SHA、文件 blob SHA |
| POST | changes/preview | 安全构造修改，返回 diff 与短期 draftId |
| POST | changes/commit | 提交已预览草稿；需稳定 idempotencyKey |
| GET / PUT | settings/model | 返回无密钥配置 / 修改进程内模型配置 |
| GET / POST | source/repos、source/authorize、source/search、source/read | 注册仓库元信息、外发授权、有界搜索与按行读取 |
| POST | agent/chat | 有界工具循环，只生成建议，不执行提交 |

手动点击“保存到 GitHub”会先在服务端构造预览，再立即提交；Agent 修改必须另外勾选确认并提交。失败或冲突保留本地草稿，不声称已保存。删除需要明确确认。重试同一请求复用幂等标识，可能执行但响应丢失的写入先核验 GitHub，不盲目重复。SSH 传输将候选提交以私密事务元数据持久化，重启后也先核实；HTTP 传输的候选和服务层草稿仍为内存状态，重启后须重新预览，不能盲目重发旧请求。GitHub SHA 冲突、保护分支或权限拒绝均不会被绕过。

## 题库编辑与稳定 ID

已发布 GitHub 是唯一正式内容源，草稿不算已发布内容。`docs/` 中以三级标题编号的问题按实际 Markdown 边界定位，代码围栏内的标题不算问题；答案子标题应使用四级及以下。更新或删除只作用于目标题块，保留相邻题、来源和事实边界。新增题从现有问答导读分配新编号，编号保留记录在 `data/web-editor-state.json`，删除的编号不复用。

`questions/` 和 `supplements/` 来自 `data/questions.json`。对这些题修改标题/参考回答会修改规范数据，调用部署版本自带的可信生成器，在隔离临时目录重新生成关联 Markdown 和索引，一次原子 Git 提交；不执行 GitHub 仓库下载的代码。Q/E 写入前还核对远端生成器 SHA 与部署可信生成器一致，并确认未修改数据的完整生成物基线，防止回退别人更新的模板。证据、易错点、追问与技术边界保留。使用 `source_path` 固定原文件路径，避免改题名改变“路径#题号”的学习进度 ID。新增题当前统一写入已有 `docs/` 问答导读；不创建未经证据审核的来源题。删除唯一来源题会被完整性检查拒绝，需先在仓库明确调整来源资料。

题目删除后，现有进度记录保留为孤立记录并退出当前题目统计；恢复同 ID 可找回记录。既有进度存储键不变，不自动清理或上传。

## 模型与源码工具

默认模型关闭，手动 CRUD 不受影响。管理员可在页面配置允许的 Base URL、模型和 key；key 仅进程内暂存，页面只显示是否配置，空 key 表示保留，改变供应商地址必须重新输入或明确清除旧 key。供应商域名/端口需先由服务器允许，页面不能授予任意服务器网络访问。

实际外连只使用 HTTPS，固定原域名 TLS/SNI/证书校验，验证全部 DNS 结果并连接到已验证数字地址，核验连接对端，拒绝重定向、保留/内网/云元数据地址。内部模型仅能通过后端预配置的完整端点明确例外授权。服务不是开放 HTTP 代理。

Agent 只能读取本次选择并授权的题目、搜索/读取已注册源码、产生结构化增改删建议与 diff；没有 commit、shell、任意 URL 或任意本机文件工具。仓库资料始终是不可信数据，不能改变权限。源码引用绑定完整 commit SHA、文件路径和行号，文本检索结果说明扫描范围与截断；本版没有编译器语义索引或向量库。

默认只注册题库；经明确批准，可在服务端注册 `hejulian2004/ssh_mobile`、`hejulian2004/testDemo`、`hejulian2004/word-crush-app` 三个源码仓库。其他仓库明确拒绝，三个项目适配器只读。仓库可见性由元信息核验，未核验时按私有保守处理。向模型发送源码须在页面确认供应商、仓库、完整提交和安全路径子集；切换题目、仓库、版本、路径或供应商撤销旧授权。私有来源建议公开提交另需服务端二次确认，不能把模型读取授权当作公开发布授权。源码路径 allowlist 排除凭据、隐藏路径、符号链接、构建产物和超限文件。不得把私有片段未经确认提交到公开题库。

默认一次并发、每次最多 4 轮模型调用、单轮最多 3 个工具、输出 1536 tokens、每日最多 50 次供应商调用和 100000 保守 Token 预留。限制是服务端强制的调用/容量控制，非货币费用承诺；重启会重置进程内计数，部署前还需供应商侧硬预算。模型可不支持工具调用，此时仅能提供文本回答，不能假称生成了可提交修改。近期对话由服务器按已认证会话隔离，最多保留 4 个完整轮次、40KB、20 分钟，共最多 20 个对话。继续对话只复用相同供应商配置及相同题目/源码授权范围的历史；范围、版本或供应商变化会清空旧历史，避免把此前授权的资料发给新的目标。页面明确披露历史发送范围，并可开始新对话；不接受浏览器伪造的 system/tool 历史。退出清除对应会话历史，重启清空全部历史。

## 测试与本地准备

```bash
python3 -m unittest discover -s web/server -t . -p 'tests_*.py' -v
python3 -m unittest discover -s tests -p 'test_*.py'
python3 scripts/build.py --check
python3 scripts/validate.py
cd web
npm test
npm run build
```

后端测试注入 MemoryAdapter 和模型 stub，不写 GitHub、不消耗真实模型 API、不需要生产配置。原版静态加载器和快照仅保留为迁移回归测试资料，不包含在新公开 dist 中。

本地验证范围与未运行项目见 [验证记录](VALIDATION.md)。生产配置与上线需要单独批准，见 [部署准备](DEPLOYMENT.md)。不要用测试密码、签名密钥或 MemoryAdapter 启动生产服务。
