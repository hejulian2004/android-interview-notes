## 参考回答提纲

同步屏障暂时阻止屏障后的普通同步消息被选中，允许符合条件的异步消息继续执行，服务于特定调度需求。说明普通消息与异步消息的区别，再结合所读 Android 版本源码解释屏障插入和移除。

## 易错点

“异步消息”不是在新线程执行；业务代码不应依赖隐藏 API 随意插入屏障。
