## 参考回答提纲

重载依据可见候选与参数等编译期信息选定签名；重写由运行时接收者的实现参与动态分派。还要区分 static 方法隐藏、private 方法和协变返回类型，避免只用“方法名相同”描述。

## 易错点

仅改变返回类型不能构成普通 Java 方法重载。
