## 参考回答提纲

从 GC Roots 出发分析引用可达性，再说明收集器如何回收不可达对象。标记、复制、整理等是不同策略，代际与并发行为依赖实现；要区分停止世界阶段和并发阶段。

## 易错点

回收不可达对象不能解决“仍被错误引用”的泄漏，也不保证调用 System.gc 就立即回收。
