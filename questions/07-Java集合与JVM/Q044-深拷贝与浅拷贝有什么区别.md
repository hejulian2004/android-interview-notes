## 参考回答提纲

浅拷贝复制对象字段值，引用字段仍可能指向同一子对象；深拷贝需要定义要复制的对象图与共享边界。对循环引用、文件句柄、线程等资源不能简单递归复制，通常应设计明确的复制协议。

## 易错点

data class.copy 或 Object.clone 不能被笼统当作递归深拷贝。

## 延伸追问（整理者设计，不是原帖原题）

复制包含循环引用的图结构，怎样既终止递归又保留共享关系？
