## 参考回答提纲

基本类型复制其值；引用类型复制引用值。因此被调函数可以修改引用指向对象的状态，但给局部参数重新赋对象不会替换调用者变量。用交换两个对象引用的反例检验理解。

## 易错点

“引用类型参数”与“按引用传参”不是一回事。
